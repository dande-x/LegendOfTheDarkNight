# 分支流程 · 经济养成系统（商人/分解/锻造/精炼）策划文档

> 归属：暗夜传奇致敬传奇改版
> 前置依赖：武器系统、怪物系统（掉落表）完成后体验更完整，但逻辑可独立开发
> 状态：待开发（分子 agent 实现）

---

## 一、目标

补齐经济循环：**商人商店 + 装备分解（回收）+ 装备锻造（合成）+ 装备精炼（强化）**，让「打怪掉落 → 变现 → 消耗 → 更强」形成闭环。

---

## 二、四大子系统

| 系统 | 传奇化命名 | 功能 | 消耗 | 产出 |
|------|-----------|------|------|------|
| 商人 | 神秘商人 | 买卖装备/药水/强化石 | 金币 | 装备、药水、强化石 |
| 回收 | 分解 | 装备 → 金币 + 强化石 | 装备 | 金币、强化石 |
| 合成 | 锻造 | 3 同品质同部位 → 1 高品 | 3 装备 + 金币 | 高 1 品质装备 |
| 强化 | 精炼 | 装备 +0~+12 | 强化石 + 金币 | 属性提升 |

---

## 三、强化石（贯穿三大系统的硬通货）

- **来源**：Boss 必掉、分解稀有+装备产出、商人出售、主线任务奖励（预留）。
- **新物品**：`enhance_stone`（强化石），入背包（非装备槽位），需在 `Inventory` 增加材质/计数字段。

---

## 四、数值规则（沿用 v1.0 方案）

> 当前运行基线（2026-08-27）已针对刷钱速度收紧：装备买入倍率为 **12**、卖出倍率为 **1.5**，强化出售返还为每级 **25 金**；怪物金币按 **0.80** 倍、主线任务金币按 **0.75** 倍发放。下方的 v1.0 公式保留作原始设计对照。

### 4.1 装备售价

```
售价 = floor((atk*2 + def*1.5 + hp*0.3) × RARITY.mult × 8)
```

### 4.2 分解产出

```
金币 = floor(ItemScore × RARITY.mult × 3)   -- 约为售价 37.5%
强化石：稀有=1, 史诗=2, 传说=4（普通/优秀=0）
已强化装备：返还 50% 已消耗强化石（向下取整）
```

### 4.3 锻造（三合一）

```
3 × 同品质同部位 + 金币 → 1 × 高1品质同部位（随机模板，封顶传说）
费用 = 100 × 合成后品质层级（优秀=1, 稀有=2, 史诗=3, 传说=4）
30% 概率附加随机强化等级 (+1~+2)
```

### 4.4 精炼（+0~+12）

```
每级属性：atk/def +4%，hp +2%（向下取整，至少 +1）
```

| 等级 | 强化石 | 金币 | 成功率 | 失败 |
|------|--------|------|--------|------|
| +1~+3 | 1 | 200 | 100% | — |
| +4~+6 | 2 | 500 | 90% | 不掉级 |
| +7~+9 | 4 | 1500 | 70% | 掉 1 级 |
| +10~+12 | 8 | 4000 | 50% | 掉 1 级 |

- **保护**：+9 以上失败不掉到 +8 以下（保底）。
- **保护石**（可选道具，商人出售）：失败不掉级。

## 五、实现要点

### 5.1 数据模型扩展（`Inventory.lua`）

- 装备实例增加 `enhance` 字段（强化等级，默认 0）。
- `SerializeItem` / 反序列化同步 `enhance`。
- `RecalcBonus` 纳入强化加成：`atk * (1 + 0.04*enhance)` 等。

### 5.2 新增 API（建议放 `Inventory.lua` 或独立 `Enhance.lua`）

```lua
Inventory.Recycle(item)               -- 分解
Inventory.Forge(items3)               -- 锻造
Inventory.Enhance(item)               -- 精炼（含成功率、掉级、保护石判定）
Inventory.GetEnhanceStoneCount()      -- 强化石数量
```

### 5.3 商人（新增 `Merchant.lua`）

- 每图出生点刷「神秘商人」NPC（复用 mech_humanoid 骨架 + 中立配色，或程序化人形）。
- 玩家靠近交互 → 打开商店面板（三栏：消耗品 / 装备 / 强化材料）。
- 货架按当前地图等级档随机刷 6 件装备，每 5 分钟或手动花金币刷新。
- 商人兼任「分解」入口。

### 5.4 UI（`GameUI.lua`）

- 商店面板：复用 `ShowCharacterPanel` 的弹窗样式，新增「商店」面板。
- 装备详情弹窗新增「强化」「分解」按钮。
- 背包 Tab 新增「锻造」入口 + 批量分解开关。

---

## 六、验收标准

1. 商人可买卖装备、药水、强化石。
2. 装备可分解为金币 + 强化石，传说品质二次确认。
3. 3 件同品质同部位可锻造为高 1 品质。
4. 装备可精炼到 +12，成功率/掉级符合上表。
5. 强化后的属性加成正确体现在角色面板与战斗。
6. 强化等级、强化石数量可存档/读档。
