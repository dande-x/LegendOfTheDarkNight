# 分支流程 · 经济养成系统（商人 / 分解 / 锻造 / 铁匠强化）

> 归属：暗夜传奇致敬传奇改版
>
> 当前版本：v2.0（2026-08-27）
>
> 状态：已实现，数值与交互以 `scripts/Enhance.lua`、`scripts/Inventory.lua`、`scripts/BlacksmithPanel.lua` 为准。

## 一、设计目标

经济循环应当服务于战斗成长，而不是把刷怪卖装备变成唯一收益线：

`打怪掉落 → 筛选装备 → 商人出售 / 分解回收 → 在铁匠处锻造或强化 → 提升战力 → 挑战更高等级地图`

本轮调整解决三个问题：

1. 强化石被移除，强化不再依赖随机材料库存；强化只能在安全区铁匠处完成。
2. 锻造由“三合一”改为“五合一”，让高品质装备需要更长的收集周期。
3. 买入价格提高、卖出价格降低，且怪物与任务金币统一折算，压低刷钱速度。

## 二、服务入口与职责

| 服务 | 入口 | 功能 | 资源消耗 | 产出 |
|------|------|------|----------|------|
| 神秘商人 | 安全区商人 NPC | 购买药水、装备；出售背包装备 | 金币 / 装备 | 物品或金币 |
| 分解 | 装备详情或商人出售流程 | 销毁一件装备并回收金币 | 装备 | 金币 |
| 铁匠 | 安全区铁匠 NPC | 打开“锻造 / 强化”双 Tab | 装备、金币 | 高品质装备或强化等级 |

强化入口不再出现在角色/背包装备详情的可执行按钮中。详情页只展示当前强化等级、下一次强化提示，并引导玩家“前往安全区铁匠”。

## 三、装备经济规则

### 3.1 基础价值

装备基础分统一为：

```text
ItemScore = atk × 2 + def × 1.5 + hp × 0.3
```

品质倍率：普通 `1.0`、优秀 `1.3`、稀有 `1.6`、史诗 `2.0`、传说 `2.5`。

### 3.2 商人买入 / 卖出

```text
玩家买入价 = floor(ItemScore × 品质倍率 × 12)
玩家卖出价 = floor(ItemScore × 品质倍率 × 1.5)
             + 强化等级 × 25
```

买入价约为基础卖出价的 8 倍；强化返还只保留每级 25 金，不能通过“买入 → 强化 → 卖出”套利。药水仍按各自配置价格购买。

### 3.3 分解

```text
分解金币 = floor(ItemScore × 品质倍率 × 1.5)
         + floor(累计强化金币投入 × 20%)
```

分解不产出强化石。传说装备、穿戴中的装备会弹出二次确认；分解完成后装备实例立即销毁，收益一次性发放，旧引用不能重复结算。

## 四、铁匠锻造规则（五合一）

### 4.1 配方

```text
5 × 同品质 + 同部位 + 同职业要求的装备
    + 锻造金币
    → 1 × 同部位下一品质装备
```

- 武器必须满足同一 `classReq`；屠龙是唯一职业通用的终极武器。
- 材料必须来自当前背包的五个不同实例；已装备物品不会被自动选中。
- 铁匠按“未强化优先、属性较低优先”的顺序自动取材，避免玩家误消耗高价值装备。
- 品质到传说后封顶，不生成更高品质的空壳装备。
- 成品有 30% 概率附带 `+1` 或 `+2` 强化；材料强化等级不会继承。

### 4.2 锻造费用

```text
优秀 = 100 金
稀有 = 200 金
史诗 = 300 金
传说 = 400 金
```

表中的品质指“成品目标品质”。锻造页会显示当前同组库存、`5/5` 进度、自动选择的材料、目标装备、费用和可锻造次数；每次点击只消耗一组五件材料并产出一件。

## 五、铁匠强化规则（+0 至 +12）

### 5.1 属性成长

每提升一级，按装备基础属性计算累计加成：

```text
攻击 / 防御加成 = floor(基础值 × 4% × 强化等级)，至少 +1（基础值 > 0 时）
生命加成       = floor(基础值 × 2% × 强化等级)，至少 +1（基础值 > 0 时）
```

强化等级写入装备实例 `enhance`，装备栏、角色属性和战斗结算都读取同一实例值。

### 5.2 单次强化费用与失败结果

| 目标等级 | 铁匠费 | 成功率 | 失败结果 |
|----------|--------|--------|----------|
| +1 ~ +3 | 300 金 | 100% | 保持当前等级（实际必定成功） |
| +4 ~ +6 | 750 金 | 90% | 保持当前等级 |
| +7 ~ +9 | 2,000 金 | 70% | 保持当前等级 |
| +10 ~ +12 | 5,000 金 | 50% | 保持当前等级 |

每次尝试都会扣除铁匠费，无论成功或失败都不返还。达到 `+12` 后按钮置灰并显示“已达最高强化”。

### 5.3 强化界面交互流程

1. 玩家进入安全区，点击铁匠交互按钮“锻造 · 强化”。
2. 面板默认保留上次打开的 Tab；选择“强化”后，左侧列出可强化的背包与已穿戴装备。首次打开时已穿戴装备优先，点选后当前装备置顶，刷新不会丢失选择。
3. 选中装备后，右侧同时显示当前属性、下一等级属性、金币费用和成功率，并明确失败不掉级。
4. 成功率低于 100% 时弹确认框，提示失败只损失本次铁匠服务费。
5. 操作完成后只刷新强化页和金币计数，保持当前 Tab 与选中装备，不把玩家送回锻造页。
6. Toast 明确反馈“成功 / 失败 / 金币不足”；失败时显示最终等级。
7. 关闭面板可点击固定“返回”按钮、遮罩或按 `ESC`，只关闭当前浮层，不穿透到底层界面。

## 六、存档与兼容

- 存档版本升为 `2`；新存档保存装备 `enhance` 和金币。
- 新存档不再写入强化石字段。
- 读取旧版存档时，旧 `enhanceStones` 按每颗 120 金一次性折算到金币，并在恢复成功后立即写回新版存档；重复读档不会重复折算。
- 存档恢复仍以本地装备模板为准，非法职业装备不会进入装备栏；背包中的异职业装备可出售或分解。

## 七、代码接口

```lua
-- 纯规则（scripts/Enhance.lua）
Enhance.FORGE_MATERIAL_COUNT       -- 5
Enhance.ForgePick(items)           -- 校验五件材料
Enhance.ForgeCost(targetRarity)    -- 目标品质费用
Enhance.EnhanceCost(targetLevel)   -- 金币/成功率
Enhance.GetEnhanceGoldSpent(level)  -- 累计强化投入
Enhance.Recycle(item)               -- 分解金币与强化返还

-- 运行时背包（scripts/Inventory.lua）
Inventory.GetForgeRecipes()         -- 实时配方进度
Inventory.ForgeRecipe(recipe)       -- 自动取五件并锻造
Inventory.EnhanceItem(item)       -- 铁匠强化
Inventory.RecycleItem(item)         -- 分解并结算金币
```

## 八、验收清单

- [x] 强化只能从安全区铁匠进入，铁匠有“锻造 / 强化”两个 Tab。
- [x] 强化只消耗对应金币，失败不掉级，不使用任何强化材料。
- [x] 锻造必须凑齐五件同组装备，材料自动选择且不会消耗已装备物品。
- [x] 强化页显示属性预览、金币、成功率和失败不掉级说明。
- [x] 强化结果明确反馈成功或失败，刷新后保留上下文。
- [x] 分解只返金币与少量累计强化投入，不再生成强化石。
- [x] 旧存档强化石可一次性折算，新存档不再持久化该字段。
- [x] 买入倍率、卖出倍率、怪物金币与任务金币折算共同抑制刷钱。
