## 一、最初的目标与方案（背景）

### 1.1 原始诉求

用户希望把「只有基础动作玩法」的游戏，完善成完整的传奇类 ARPG，核心诉求包括：

1. **主线任务**（要有剧情起伏，不是流水账刷怪）
2. **多等级地图**（不同地图不同风格）
3. **怪物扩充**（不同怪物不同建模）
4. **商人**（买卖装备）
5. **装备回收 / 合成 / 强化** 系统

### 1.2 致敬传奇的命名要求（用户明确指定）

- **地图**：比奇省（银杏山谷/比奇新村）、盟重土城、水上城市、沃玛寺庙、祖玛寺庙
- **怪物**：稻草人、蛤蟆、多钩猫、钉耙猫、鹿、狼、毒蜘蛛、半兽人、半兽勇士、白野猪等
- **武器**：乌木剑、八荒、炼狱、井中月、裁决之杖、屠龙（战士链），法师/道士有对应链
- **BOSS**：牛魔王、蚁后、火龙王、沃玛教主、半兽勇士、白野猪

### 1.3 主线剧情设计（三幕 + 终章，每章一反转一高潮 Boss）

- **第一幕「边城烽火」**（比奇省，Lv1~15）：家园被半兽人夜袭、师父战死 → 追查真凶 → 反转：守卫队长是叛徒 → 高潮 Boss「半兽勇士」
- **第二幕「黄沙盟重」**（盟重土城，Lv16~30）：护送商队、深入猪洞 → 反转：城主被掉包 → 高潮 Boss「白野猪」
- **第三幕「怒海寻踪」**（水上城市，Lv31~44）：蚁穴调查 → 反转：师父另有身份、复仇对象重置 → 高潮 Boss「蚁后」
- **终章「屠龙之战」**（沃玛寺庙→祖玛寺庙，Lv45~50）：集齐屠龙残片 → 沃玛教主 → 火龙王 → 最终 Boss「牛魔王」

### 2.2 已完成的功能点

1. **主线任务**：18 节点（含 6 场 Boss 战），每个任务带多句剧情对话（`PlayDialogue` 逐句播放 + 点击继续），任务开始/完成自动触发对话，任务追踪条显示章节+目标+进度+目标地图
2. **多地图**：5 张地图，按图刷怪（spawnPool），切图时重铺地面+差异化装饰（沙丘/珊瑚/石柱/岩浆）+雾色，F5 调试切换
3. **怪物**：经典名替换 + 新增怪，蛤蟆/猫/狼/白野猪/蚁后用**独立程序化骨架**（非跨物种复用）
4. **安全区**：每图出生点 8 米安全区，蓝色发光尖锐针状（Cone 尖朝外）方形虚线边界，安全区内不刷怪、怪物不追击、玩家不能攻击
5. **NPC 系统**：管家（对话传送，统一 100 金币）+ 商人（双 tab：购买药水/装备 + 出售背包装备）
6. **装备价值系统**：买入价 `score×品质倍率×12`，卖出价 `score×品质倍率×1.5 + 强化每级+25`；分解倍率 `1.5`，怪物金币按 `0.80` 倍、主线金币按 `0.75` 倍发放，防止刷钱过快
7. **经济系统**：分解（金币+强化石）、锻造（3合1）、精炼（+0~+12，成功率阶梯）、强化石
8. **存档**：地图/任务进度/装备强化等级/强化石 全持久化

### 2.3 已修复的关键 bug（重要，避免重复踩坑）

- **NPC 按钮点击失效**：根因是 `SetNPCInteract` 在 HandleUpdate 每帧被调用，内部每次 Remove+AddChild 重建按钮，导致触摸按下时按钮被销毁、`OnClick` 永不触发。修复：加状态缓存（`npcInteractKey` + `npcInteractLabel`），状态不变不重建。
- **主线 Boss 任务卡关**：原 Boss 任务 target 与地图守关 Boss 错位（如第一幕 target 沃玛教主但地图 boss 是半兽勇士）。已修复对齐：q006=半兽勇士、q009=白野猪、q012b=蚁后、q014b=沃玛教主、q015=火龙王、q016=牛魔王。
- **触屏点击**：面板行项必须用 `onClick`（不是 `onPointerUp`，触屏滑动会失效）。

## 四、关键约束与规范（务必遵守）

1. **代码放 `scripts/`，资源路径不加目录前缀**（引擎已配置 scripts/assets 为资源根）
2. **长度单位是米，Y-up 左手坐标系**（与 Unity 一致）
3. **UI 用 `urhox-libs/UI`**（原生 UI 已废弃），交互用 `onClick` 不用 `onPointerUp`
4. **枚举用常量**（`MOUSEB_LEFT` 而非数字 0）
5. **`urhox-libs/` 只读**，不要改引擎库文件
6. **构建流程**：改完 Lua 后用 `maker_build` 构建（不要用 git commit/push 提交 Maker 项目，Maker 有自己的提交机制）
7. **Maker 构建会推送 origin（Maker 远端）**；GitHub 是 `github` 远端，需单独 `git push github main`
8. **Lua 数组从 1 开始**
9. **每个新 .lua 文件需要配 .meta**（含 uuid，格式 `{"uuid": "..."}`）
