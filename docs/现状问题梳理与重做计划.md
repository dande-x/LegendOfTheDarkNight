# 暗夜传奇 · 现状问题梳理与重做计划

> 版本：v3.0（诚实复盘 + 修复路线）
> 结论先行：之前的实现是「换名 + 复用骨架」的半成品，未达到游戏开发标准。以下逐项诊断根因、给出修复方案与优先级。

---

## 一、五大问题诊断（全部属实）

### 问题1：地图完全一样，未按风格重新建模

**现状**：`CreateFloor(groundColor)` 只改了地面主色，`CreateSceneDecorations()` 完全没参数化——5 张地图共享同一套「枯树 + 墓碑 + 石堆 + 桥」暗黑装饰。

**根因**：我偷懒只传了 `groundColor`，没把装饰风格纳入地图配置。

**修复方案**：为每张地图定义独立的装饰风格配置，用程序化几何（Box/Cylinder/Sphere + 材质色）为每张图构建**差异化的标志性场景元素**：

| 地图 | 标志性装饰 | 主色调 |
|------|-----------|--------|
| 比奇省·银杏山谷 | 银杏树(金叶)+ 农田篱笆 + 村庄木屋 | 翠绿+金黄 |
| 盟重土城 | 沙丘 + 仙人掌 + 破败城墙 + 帐篷 | 黄沙+土黄 |
| 水上城市 | 水域平台 + 栈桥 + 灯塔 + 珊瑚礁 | 深蓝+青 |
| 沃玛寺庙 | 石柱 + 火把 + 祭坛 + 骷髅堆 | 灰蓝+幽绿 |
| 火龙魔窟 | 岩浆池 + 熔岩石 + 岩浆裂隙 | 焦黑+赤红 |

**优先级**：P1（纯程序化，可立即做）

---

### 问题2：怪物错误复用建模，需要独立建模

**现状**：新增怪物全部复用错误骨架：

| 怪物 | 误用骨架 | 应表现 |
|------|---------|--------|
| 蛤蟆 | scarecrow(稻草人) | 蛙类两栖 |
| 多钩猫/钉耙猫 | deer(鹿) | 猫科四足 |
| 狼 | orc(半兽人) | 狼形四足 |
| 白野猪 | orc(半兽人) | 猪形 |
| 蚁后 | spider(毒蜘蛛) | 大型蚁类 |
| 沃玛教主 | golem(石魔) | 恶魔人形 |
| 火龙王 | serpent(巨蟒) | 龙形 |
| 牛魔王 | golem(石魔) | 牛头人形 |
| 赤焰魔/噬魂兽 | golem/orc | 各需独立 |

**根因**：我为了「低成本落地」直接复用 `monsterType`，只改了 `name` 和 `scale`。

**修复方案**：用 Maker `create_3d_asset` 为每个错误复用的怪物生成独立 3D 模型（low-poly 风格化），接入 `MonsterSkeleton` 的 `MODEL_MONSTERS` 映射。

**优先级**：P3（3D 资产生成，最重，需逐个生成 + 用户确认 review）

### 问题3：没有按策划案实现剧情

**现状**：`Quest.lua` 只有「击杀 N 只怪」的计数，`desc` 文本只在任务追踪条显示，**没有对话演出、没有章节转场、没有 NPC 互动、没有反转呈现**。策划案里的「三幕+终章、每章一反转一高潮」完全没落地。

**根因**：我把剧情简化成了「任务名 + 描述文本」，没有实现对话/演出系统。

**修复方案**（新增剧情演出系统）：
1. Quest 任务增加 `dialogues` 字段：每个任务挂接一段**多句对话**（NPC 台词 + 旁白），在任务开始时播放。
2. 新增 `GameUI.ShowDialogue(lines, onDone)`：底部对话框 + 逐句播放 + 点击继续。
3. 章节转场：每幕开始时播放**章节标题演出**（黑屏 + 章名渐显）。
4. 反转呈现：Boss 战前播放揭示真凶的对话。
5. 存档记录对话已读状态（避免重复播放）。

**优先级**：P1（纯代码，可立即做）

---

### 问题4：不同地图应该有适合等级的怪物，而不是都一样

**现状**：`MapZone.DEFS` 的 `spawnPool` 与地图等级区间**严重不匹配**：
- map_mz(10-24) 池子里有「半兽人」(8级) 这种低级怪
- map_sc(25-34) 池子里有「骷髅将军」(22级)
- map_wm(35-44) 池子里有「赤焰魔」(28)「巨蟒」(32) 低级怪
- map_zm(45-50) 池子里全是 28-38 的低级怪

**根因**：怪物数量不足（25-34、35-44、45-50 三个区间几乎没有专属怪），导致高级图只能塞低级怪凑数。

**修复方案**：
1. 补齐 25-50 区间怪物（每个区间至少 4-6 种专属普通怪）
2. 重做 `spawnPool`，严格按 `minLevel~maxLevel` 匹配
3. Boss/精英不进普通刷怪池（由守关机制单独刷）

**优先级**：P1（纯数据，可立即做）

---

### 问题5：整体偷懒，未按游戏开发标准完成

**根因**：我为了「快速交付」牺牲了品质，把「致敬传奇」做成了「换名字」。

**修复原则**：
- 数据层（怪物/地图/任务）要完整、自洽
- 逻辑层（剧情/刷怪/切换）要真实实现，不做空壳
- 表现层（建模/演出/装饰）要逐项落地
- 每个阶段构建验证，不做「构建通过就算完成」
