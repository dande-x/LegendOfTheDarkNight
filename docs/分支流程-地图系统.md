## 一、目标

把当前「单张 120×120 暗黑地表 + 全表刷怪」改造为 **5 张传奇地图 + 按图分区刷怪 + 传送阵切换 + 守关 Boss 时机**，与主线任务系统联动（任务推进解锁地图）。

## 三、实现要点

### 3.1 地图配置表（新增 `scripts/MapZone.lua`）

```lua
MapZone.DEFS = {
    map_bq = {
        name = "比奇省 · 银杏山谷",
        minLevel = 1, maxLevel = 9,
        groundColor = Color(0.16, 0.24, 0.14, 1.0),   -- 翠绿草地
        fogColor = Color(0.26, 0.29, 0.34, 1.0),
        spawnPool = { "稻草人", "蛤蟆", "多钩猫", "钉耙猫", "鹿", "幽灵", "骷髅" },
        boss = "半兽勇士",
        spawnPos = Vector3(0, 0, 0),
    },
    map_mz = { ... },
    map_sc = { ... },
    map_wm = { ... },
    map_zm = { ... },
}
```

### 3.2 地图切换

- `MapZone.SwitchTo(mapId)`：
  1. `Combat.Clear()` 清怪 + 清地面掉落物
  2. 重铺地面（复用 `main.CreateFloor`，按 `groundColor` 换主色）与装饰（按地图风格）
  3. 更新 `Zone` 雾色 / 主光色
  4. 玩家传送到 `spawnPos`
  5. 记录 `currentMapId`，写入存档

### 3.3 传送阵

- 每张地图出生点附近放一个「传送阵」节点（程序化几何：发光圆环/石碑），玩家靠近 → 弹出地图选择（UI 复用现有面板样式）。
- 已解锁地图才可选；未解锁显示「需完成主线任务 X」。

### 3.4 按图刷怪（改造 `Combat.UpdateSpawner`）

- `Combat.SpawnEnemy` 增加 `mapId` 参数，从 `MapZone.DEFS[mapId].spawnPool` 中按等级加权选取，替换现有「全 ENEMY_DEFS 按等级」逻辑。
- **守关 Boss 时机**：守关 Boss 只在「当前主线任务 = 该图守关 Boss 击杀任务」时刷新，平时不刷（`Quest.GetCurrent().target == mapDef.boss` 才允许 `forceDef` 刷出）。

### 3.5 存档扩展

- `SaveSystem.CreateSnapshot` 增加 `mapId` 字段；`RestorePlayer` / 读档后 `MapZone.SwitchTo(saveData.mapId)`。

---

## 四、验收标准

1. 新建角色出生在 `map_bq`，地面为翠绿。
2. 击杀任务目标怪 → 完成任务 → 解锁下一地图（传送阵可选）。
3. 不同地图刷出不同怪物池，等级匹配。
4. 守关 Boss 只在对应主线任务激活时刷新。
5. 读档回到上次所在地图。
