# 分支流程 · 武器系统（传奇经典进阶链）策划文档

> 归属：暗夜传奇致敬传奇改版
> 前置依赖：无（可独立实施）
> 状态：待开发（分子 agent 实现）

---

## 一、目标

把现有武器模板（`Inventory.lua ITEM_TEMPLATES` 中 `itemType == "weapon"` 的条目）替换为传奇经典进阶链，三职业各 6 档。

---

## 二、三职业武器进阶链

```
武士：乌木剑 → 八荒 → 炼狱 → 井中月 → 裁决之杖 → 屠龙
法师：乌木剑 → 海魂 → 偃月 → 魔杖 → 骨玉权杖 → 嗜魂法杖
道士：乌木剑 → 半月 → 降魔 → 无极棍 → 龙纹剑 → 逍遥扇
```

> 说明：传奇中「乌木剑」为新手通用武器（三职业皆可用），故第一档三职业共用同名同 id 或各自独立 id 但同名「乌木剑」。
> 「屠龙」为战士终极（原传奇为战士专属），本设计放宽为**全职业可用传说级终极**（`classReq` 设 nil 或三职业都允许），作为终章剧情核心道具。

## 四、实现要点

1. **只改武器段**（`itemType == "weapon"`），其余部位（头盔/盔甲/项链/手镯/戒指/腰带/鞋子）本轮不动，留给「装备系统」分支。
2. **新增 item id 需全局唯一**，如 `sword_jzy`（井中月）、`sword_cjzz`（裁决之杖）、`staff_hs`（海魂）、`staff_shfz`（嗜魂法杖）、`bell_wm`（乌木剑-道士）、`bell_xyjs`（逍遥扇）等。
3. **掉落表联动**：改名后，`DROP_TABLES` 中引用旧 id 的条目**不受影响**（id 不变只改 name），但新增武器需在掉落表里加权重条目（或由怪物系统分支统一补）。
4. **classReq**：屠龙设 `classReq = nil`（或三职业都放开），其余保持各自职业限定。
5. **传说品质**：屠龙、嗜魂法杖、逍遥扇设 `LEGENDARY`，颜色金色（`RARITY.LEGENDARY.color`）。

---

## 五、验收标准

1. 商店/掉落/背包中武器显示经典名（乌木剑、炼狱、屠龙等）。
2. 三职业各 6 档武器，品质梯度合理。
3. 屠龙为金色传说，全职业可装备。
4. 构建通过，无「找不到 item」报错。
