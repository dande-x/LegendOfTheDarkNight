# 分支流程 · 怪物系统（经典名替换 + 新增）策划文档

> 归属：暗夜传奇致敬传奇改版
> 前置依赖：无（可独立实施，与地图系统解耦）
> 状态：待开发（分子 agent 实现）

---

## 一、目标

1. 把现有 `ENEMY_DEFS` 的 `name` 字段替换为传奇经典名；
2. 新增传奇经典怪物（蛤蟆、多钩猫、钉耙猫、半兽勇士、白野猪等）；
3. 补齐高级怪掉落表（当前仅 6 张）。

---

|-----------|------|-----------|------|
| 幽灵鹿 | **鹿** | 蜘蛛 | **毒蜘蛛** |
| 狼人 | **狼** | 暗影蛛后 | **蚁后** |

| 噬魂兽 | **噬魂兽**（保留） | | |

> ⚠️ 注意：`MonsterSkeleton.TYPES` 里的 `name` 字段仅作显示用途，不影响骨架构建（骨架由 `monsterType` 决定）。**只改 `Combat.ENEMY_DEFS` 的 `name` 即可**，`MonsterSkeleton` 无需改动。

> ⚠️ 注意 2：`Inventory.DROP_TABLES` 的 key 也是怪物名（如 `["幽灵鹿"]`）。改名后必须**同步改掉落表 key**，否则掉落失效。

## 五、验收标准

1. 游戏内击杀「蜘蛛」后飘字/血条显示「毒蜘蛛」等经典名。
2. 新增怪物正常刷出、有掉落。
3. 高级怪（狼、石魔等）击杀后有对应品质掉落。
4. 改名后所有怪物仍有掉落（无「无掉落表」的怪）。
