## 一、世界观与主线剧情（三幕 + 终章，有起伏）

> 设计目标：**不是「接任务→刷怪→交任务」的流水线，而是每个章节都有一个情感钩子、一个反转、一场高潮 Boss 战。** 玩家在每个阶段都有「为什么而战」的动机。

### 1.1 背景

玛法大陆，人类与半兽人的战争已持续百年。三大职业（武士、法师、道士）世代守护三座城池。传说中，能号令万兽的 **屠龙宝刀** 与封印着远古魔王的 **祖玛宝藏**，是这场战争胜负的关键。而你，是一个在新手村长大的孤儿……

---

### 1.2 第一幕「边城烽火」（比奇省 · 银杏山谷，Lv1–15）

**剧情钩子：一夜之间，家园被毁，师父战死。**

- **序章 · 血夜**：开局不是「点击任务刷怪」，而是一段**家园被半兽人夜袭的演出**——师父为掩护村民战死，临终把 **乌木剑** 塞到你手里，只说了一句：「去盟重，找真相。」（情感起点：复仇 + 悬疑）
- **章1 · 幸存者**：新手村百废待兴。你要在废墟中清理入侵的**稻草人、蛤蟆、多钩猫、钉耙猫**——不是「刷 N 只」，而是「重建村庄的巡逻与清剿」，每清一片区域，村民归来一人（可视化正反馈）。
- **章2 · 疑云**：你发现这次夜袭不寻常——半兽人**有组织、有指挥**，不像野兽。一个神秘商人（引入「商人系统」）暗示：「有人在比奇城里，替半兽人开了门。」
- **转折点**：你追查到城门，却发现**是你最信任的守卫队长**勾结了半兽人。队长带着**半兽勇士**反扑。
- **高潮 Boss 战 · 半兽勇士**：击败后，队长临死忏悔，留下通往盟重的线索。你带着师父的遗愿踏上西行之路。

> **情绪曲线**：悲伤（灭村）→ 愤怒（复仇）→ 疑惑（疑云）→ 背叛（反转）→ 决意（启程）。

---

### 1.3 第二幕「黄沙盟重」（盟重土城，Lv16–30）

**剧情钩子：沙漠之城，最大的威胁竟来自「自己人」。**

- **章3 · 土城风云**：盟重土城是玛法大陆的贸易枢纽，却人心惶惶——城外**毒蜘蛛、狼、半兽人**越聚越多。你接到的第一个任务不是刷怪，而是「**护送商队**」（护送玩法，中途遭遇战）。
- **章4 · 猪洞之影**：土城东郊的**石墓（猪洞）**传来异动，传闻有**白野猪**作乱，商路断绝。你深入猪洞调查。
- **转折点**：你发现土城城主被掉包——真正的城主被囚禁，假城主正是半兽人的内应，而猪洞的骚乱只是「调虎离山」，目的掩护半兽人主力夜袭土城。
- **高潮 Boss 战 · 白野猪**：你击破猪洞深处的白野猪，夺回城主信物，揭穿假城主，守住土城。城主感激之下，告诉你真正的幕后主使指向北方——**沃玛寺庙**。

> **情绪曲线**：压抑（人心惶惶）→ 责任（护送）→ 惊恐（猪洞）→ 反转（城主被掉包）→ 荣耀（守城成功）。

---

### 1.4 第三幕「怒海寻踪」（水上城市，Lv31–44）

**剧情钩子：真相的尽头，是更大的黑暗。**

- **章5 · 海上迷城**：你循线索来到**水上城市**——一座建立在海域上的贸易城。这里的海域正被**蚁后**的蚁群侵蚀。
- **章6 · 蚁穴**：为了拿到进入沃玛寺庙的「通行证」，你必须帮水城清除蚁患，深入蚁穴。同时，你在水城遇到**旧日师父的故交**，揭开了师父当年身负的秘密——师父本是沃玛寺庙的守门人。
- **转折点**：蚁后不是元凶，它只是被**沃玛教主**的黑暗力量驱使。更残酷的是，你得知**师父当年并非战死，而是为了封印沃玛教主，自愿献祭**。你的复仇对象，从一开始就是错的。
- **高潮 Boss 战 · 蚁后**：击败蚁后，水城得救。你带着对师父的真正敬意，也带着对沃玛教主的怒火，踏入沃玛寺庙。

> **情绪曲线**：新奇（海上）→ 探索（蚁穴）→ 震撼（师父真相）→ 释然与愤怒（复仇对象重置）→ 决死（进入寺庙）。

---

### 1.5 终章「屠龙之战」（沃玛寺庙 → 祖玛寺庙，Lv45–50）

**剧情钩子：集齐屠龙，才能斩断轮回。**

- **章7 · 沃玛教主**：沃玛寺庙深处，**沃玛教主**祭起黑暗法阵。你击败它，却发现它只是「钥匙」——真正的封印在**祖玛寺庙**，而打开封印需要**屠龙宝刀**。
- **章8 · 寻刀**：屠龙宝刀散落在大陆，你要集齐残片（贯穿收集玩法，与强化/合成系统联动）。期间**牛魔王**率魔兽来抢夺残片。
- **高潮 Boss 战 A · 牛魔王**：在祖玛寺庙门口，击败前来抢夺屠龙的牛魔王。
- **最终 Boss 战 B · 火龙王**：祖玛寺庙最深处，被封印的**火龙王**即将苏醒。你用屠龙宝刀，斩断祖玛封印，终结这场延续百年的战争。
- **结局**：玛法大陆重归和平。三大城池为你立碑，师父的在天之灵得以安息。你，成为了新的传说。

> **情绪曲线**：决战（沃玛）→ 寻宝（屠龙残片）→ 危机（牛魔王抢夺）→ 终极对决（火龙王）→ 圆满（成为传说）。

---

### 1.6 剧情设计要点（反「流水账」的落地手段）

| 手段 | 说明 |
|------|------|
| **每章一个反转** | 灭村真凶是守卫队长 → 城主被掉包 → 师父另有身份 → 复仇对象重置，让玩家始终有「想知道下一步」的动力 |
| **每章一个高潮 Boss** | 半兽勇士 / 白野猪 / 蚁后 / 沃玛教主 / 牛魔王 / 火龙王，Boss 战即章节节点，而非「刷够 100 只怪」 |
| **任务类型多样化** | 巡逻清剿、护送商队、深入洞穴、收集残片、Boss 讨伐，穿插使用，避免单一「击杀 N 只」 |
| **情感 NPC** | 神秘商人、守卫队长、假城主、师父故交，用对话承载剧情，而非靠任务文本硬塞 |
| **剧情奖励即成长** | 每个章节奖励对应等级段的传奇武器（乌木剑→屠龙），把「变强」和「剧情推进」绑定 |

## 二、地图系统（传奇经典名 + 等级分区）

沿用「单场景 + 相机跟随」框架，用**地图 ID + 出生点 + 怪物池 + 地面风格**实现分区切换。

| 地图ID | 经典名 | 等级 | 地面基调 | 守关 Boss |
|--------|--------|------|---------|-----------|
| `map_bq` | 比奇省 · 银杏山谷 | 1–9 | 翠绿草地（新手） | 半兽勇士 |
| `map_mz` | 盟重土城 | 10–24 | 黄沙 | 白野猪 |
| `map_sc` | 水上城市 | 25–34 | 蓝海水域 | 蚁后 |
| `map_wm` | 沃玛寺庙 | 35–44 | 幽暗石洞 | 沃玛教主 |
| `map_zm` | 祖玛寺庙 | 45–50 | 赤红岩浆 | 牛魔王 + 火龙王 |

- **传送门**：每图出生点设「传送阵」，交互切换（复用程序化几何 + 发光材质）。
- **等级软门槛**：低于地图下限可进入（保留越级挑战的暗黑味），仅软提示「推荐等级」。
- **守关 Boss 只在对应章节任务激活时刷新**，避免平时乱刷破坏剧情节奏。
- **存档**：`currentMapId` + `chapterProgress` 写入存档，读档回到原地。

## 五、经济与养成系统（沿用 v1.0 方案，融入传奇味）

在 v1.0 已设计的框架上，仅做「命名传奇化」微调，机制不变：

| 系统 | 传奇化命名 | 机制（沿用 v1.0） |
|------|-----------|------------------|
| 商人 | **神秘商人**（主线关键 NPC，兼任商店） | 三栏货架 + 回收入口 |
| 回收 | **分解**（回收装备 → 金币 + 强化石） | ItemScore × 品质 × 3 |
| 合成 | **锻造**（3 同品质同部位 → 1 高品） | 三合一，封顶传说 |
| 强化 | **精炼**（+0~+12，耗强化石 + 金币） | 成功率阶梯 100/90/70/50% |

> 详细数值（售价公式、成功率表、强化石来源）见 v1.0 方案，本轮不变，仅统一改为传奇风格命名。
